# Review

Choose the workflow that matches the requested review. An ordinary weekly contributor report uses the text-only contributor activity workflow; select the weekly extension only when the user requests its presentation or deck. If the subject or deliverable is unclear, establish it before acting.

- [Repository review](references/daily.md) audits and repairs quality, maintenance, dependency, and pull request findings across its defined repositories.
- [Contributor activity review](references/contributors.md) compares activity with goals.
- [Weekly contributor deck](references/weekly.md) compares Terra activity with stated goals and produces a verified presentation.

Read the selected workflow completely before acting. Keep its scope, evidence, delivery, and reporting requirements. Do not treat the daily remediation workflow as authorization for changes during a weekly evidence review. The deck workflow's Drive-file maintenance is an external mutation; it requires the user's explicit authorization and is outside a read-only text review.
