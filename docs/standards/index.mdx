Reusable foundations for Terra Symposium repositories.

[Choose a package](/standards/quality/overview/) · [Contribute](/standards/contributing/guide/)

Standards maintains packages used across Terra Symposium applications. Each package has its own setup guide, public entry points, configuration reference, and known boundaries.

## Packages

| Package                                                          | Use it for                                                                     | Start here                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [@terra-symposium/standards-quality](/standards/quality/overview/)                   | Configurable source checks, safe maintenance, and repository commands.         | [Install and set up](/standards/quality/setup/)                    |
| [@terra-symposium/standards-error-boundaries](/standards/error-boundaries/guide/) | React render-error recovery and small framework-specific error helpers.        | [Use error boundaries](/standards/error-boundaries/guide/)               |
| [@terra-symposium/standards-reporting](/standards/reporting/overview/)               | Responsive Playwright runs, diagnostics, evidence artifacts, and load timings. | [Configure Playwright reporting](/standards/reporting/playwright/) |

All packages are published to the public npm registry. See [Contributing](/standards/contributing/guide/) to set up this workspace, change a package, or update these docs.

## Skills

Standards also publishes shared agent guidance for repository work, issue audits, reporting, and interface review. Browse the [Terra skill library](/standards/skills/guide/) to find the workflows and source files.
