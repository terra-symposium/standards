---
title: Tool and command checks
description: Configure external tools and repository-owned static checks.
---

Install and configure each native tool in the consuming repository. Hygiene coordinates these checks; it does not supply ESLint, Knip, TypeScript, or their native policies.

## External tools

| Check | Toggle | Fix control | Behavior |
| --- | --- | --- | --- |
| Lint | `enabledChecks.lint` | `autofix.lint` | Runs configured ESLint on selected files; fix mode passes ESLint's fix option. Set `tools.eslint` and optional `lintRoots`. |
| Knip | `enabledChecks.knip` | `autofix.knip` | Reports unused files, exports, and dependencies from configured entry points. Set `tools.knip` and review dynamic or framework-discovered usage before removal. |
| Type | `enabledChecks.type` | None | Runs selected-source or project TypeScript checks. Set `tools.tsc`, `tsconfig`, `typecheckRoots`, `typecheckExtensions`, or `typecheckCommand`. |
| Diff | `enabledChecks.diff` | None | Runs `git diff --check` in a Git worktree. Disable it for source archives. |

Knip's `knip` command and TypeScript's `types` command are available for focused runs. Type checking may inspect files beyond the changed-file set. None of these checks replaces runtime validation of untrusted input.

## Repository commands

Use `qualityCommands` only for static or hygiene checks with no native Hygiene equivalent. Keep builds, unit tests, integration tests, browser tests, and example execution in separate scripts and CI steps.

```json
{ "qualityCommands": [{ "name": "c-doc-params", "command": "make", "args": ["check-doc-params"] }], "enabledCommands": { "c-doc-params": true } }
```

Each entry needs a unique lowercase `name`, an executable `command`, and optional string-array `args`. Commands run from `root`, inherit the environment, are not limited to changed files, and fail Hygiene on a nonzero exit. Use `enabledCommands.<name>` to select one, `enabledChecks.command: false` to disable the category, or `--skip-commands` for one run. Run a single configured command with `pnpm exec hygiene domain c-doc-params`.

`recommendationCommands` has the same entry shape and uses `enabledRecommendations.<name>`, `enabledChecks.recommend`, and `--skip-recommendations`. These commands also fail Hygiene on nonzero exit and keep their own side-effect contract.
