`@terra-symposium/hygiene/core` is the API-only foundation shared by the Hygiene subpath APIs. It owns contracts and common analysis behavior, not individual findings or aggregate phase orchestration.

## Install and imports

```sh
pnpm add -D @terra-symposium/hygiene
```

```ts
import { loadHygieneConfig, qualityScope, createHygieneAnalysis, srcFiles, workingSrcFiles } from '@terra-symposium/hygiene/core';
```

## Public surface

The root export ships JavaScript and TypeScript declarations for `HygieneCfg`, `HygieneScope`, `HygieneOptions`, `CapabilityOptions`, check and autofix names, config toggle helpers, source-kind helpers, progress utilities, and file-scope functions.

`loadHygieneConfig()` reads the existing root `quality.json` or its `config/quality.json` fallback and resolves project roots and scope. `createHygieneAnalysis()` builds a shared TypeScript program and file cache. `srcFiles()` selects the configured source set; `workingSrcFiles()` applies the normal changed/untracked worktree scope.

## Package boundary

This subpath has no CLI. Use a capability subpath to run a focused check. A feature package should depend on Core for its shared contract and must not import its check implementation from the root runner. Install [Hygiene](/hygiene/1-packages/hygiene/) when you need ordered phases, the full schema, repository commands, or combined output.
