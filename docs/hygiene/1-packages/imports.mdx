---
title: Imports
description: Resolve local imports and detect repeated imports using the shared Hygiene scope.
---

`@terra-symposium/hygiene/imports` checks source imports against repository paths, configured aliases, and configured external prefixes. It also finds duplicate imported bindings through its dependency on the shared Documentation implementation.

## Install and run

<CodeBlock language='sh' code={'pnpm add -D @terra-symposium/hygiene\npnpm exec imports --all'} />

The CLI reads root `quality.json` or `config/quality.json`; `--config PATH` chooses explicitly. Changed and untracked files are the default scope. `--all` scans the configured source roots, and `--warn` disables fixes.

## Configuration

`sourceRoots`, `includeRoots`, `extensions`, `skippedDirectories`, and `skippedFiles` determine what is scanned. `aliases` maps internal import prefixes to repository paths, such as `@/` to `src/`. `externalPrefixes` marks import prefixes that should not be treated as unresolved local files. The checker does not rewrite package exports or resolve arbitrary custom runtime loaders.

## API

<CodeBlock language='ts' code={"import { checkImports, duplicateImportFindings } from '@terra-symposium/hygiene/imports';"} />

Both APIs are available from the declared root export with TypeScript declarations; `./cli` is also exported. See [the config reference](/hygiene/0-getting-started/overview/) for path semantics and [CLI workflows](/hygiene/0-getting-started/overview/) for common scope choices.
