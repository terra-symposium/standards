`@terra-symposium/hygiene` is the aggregate package for a complete ordered run. It coordinates its focused subpaths, external tools, repository commands, combined reports, progress output, and development-server helpers. It also preserves the established root, subpath, and CLI entry points for existing consumers.

## Install and run

```sh
pnpm add -D @terra-symposium/hygiene
pnpm exec hygiene quality --all
```

The package requires Node.js `>=18.18`. Its normal run selects changed and untracked source files; `--all` selects all configured source roots. `--warn` disables automatic edits. The configured `quality.json` is the single policy file: `--config PATH` selects a different file, and `config/quality.json` is discovered when no root-level file is present.

The `error-boundaries` source check is mandatory. It checks React mount roots and Astro configuration for the shared failure handling integrations, then applies supported wrappers in fix mode. Pass `--warn` to inspect without edits. Static analysis does not test whether the chosen fallback works at runtime; use an application browser test for that behavior.

## Responsibilities

- Validate and normalize the full `quality.json` schema.
- Run phases in fixed order: Format → Static quality → Framework and type checks → Repository health.
- Invoke capability APIs and configured repository tools or commands.
- Preserve JSON reports, failure exit codes, findings, and progress behavior used by the existing CLI.
- Provide GitHub reporting, the `hygiene-dev` port launcher, and existing compatibility subpaths.

The root entry point owns orchestration. Focused subpaths expose each capability's CLI or API from the same package. Start with [the package map](/hygiene/1-packages/package-map/) and [the CLI workflow](/hygiene/0-getting-started/overview/).

## Existing executables and API

The package publishes `hygiene` and `hygiene-dev`. The root export and documented subpaths, including `/cli`, `/naming`, `/object-forwarding`, `/single-use`, and `/port`, remain available for compatibility. Import a focused subpath when only one capability is needed.

`quality.json` contains source scope, check toggles, autofix policy, tool locations, command arrays, and report options. See [the schema-backed configuration reference](/hygiene/0-getting-started/overview/); do not add a second configuration file for a focused check.
