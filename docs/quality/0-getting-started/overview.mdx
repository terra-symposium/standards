The aggregate package coordinates built-in JavaScript and TypeScript checks with repository-configured tools and commands. Capability packages expose reusable check families and focused CLIs. All packages read the same `quality.json` policy.

## Run lifecycle

A full run selects a repository scope, performs the enabled check phases, and produces findings and an exit status. Fix mode may write eligible source changes; `--warn` is read-only. Configured commands remain in the aggregate runner's fixed order.
