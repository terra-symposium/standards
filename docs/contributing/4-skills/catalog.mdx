This inventory is generated from repository `.agents/skills/*/SKILL.md` files. Edit the owning skill, then run `python3 scripts/skills_catalog.py` from Standards. Shared Standards skills are also packaged in the Terra skills plugin.

## Install shared skills locally

From Standards, run `pnpm run skills:package`, then add its repository marketplace:

```sh
codex plugin marketplace add /absolute/path/to/standards
codex plugin add terra-skills@terra-skills-local
```

The versioned plugin is built from canonical `.agents/skills/` sources into `dist/`. The local marketplace uses that generated bundle. Rebuild and refresh it after edits. Cloud availability requires publishing the plugin to a workspace or reachable marketplace.
