Terra Shared packages are published publicly to npm. Consumers do not need a Terra registry token. The quality package supports Node.js 18.18 or later.

## Install quality and its tools

```sh
pnpm add -D @terra-symposium/quality prettier
```

Terra Quality coordinates tools but does not install them. Add only the tools you enable in `quality.json`; for example, add `eslint`, `knip`, or `typescript` when your repository configures those checks. If the repository contains Astro files, install Astro's Prettier plugin too:

```sh
pnpm add -D prettier-plugin-astro
```

For an Astro repository, register the plugin and parser in `.prettierrc.mjs`:

```js
export default {
	plugins: ['prettier-plugin-astro'],
	overrides: [{ files: '*.astro', options: { parser: 'astro' } }],
};
```

Add convenient scripts to `package.json`:

```json
{
	"scripts": {
		"quality": "terra-quality",
		"quality:all": "terra-quality quality --all",
		"format": "terra-quality format"
	}
}
```

Create `quality.json` at the repository root:

```json
{
  "$schema": "./node_modules/@terra-symposium/quality/quality.schema.json",
  "sourceRoots": ["src"],
  "extensions": [".js", ".jsx", ".ts", ".tsx"],
  "tools": { "prettier": "prettier" }
}
```

Then run `npx terra-quality`. The CLI reads `quality.json` from the current working directory. For a monorepo, set `sourceRoots` to package directories. For a config stored elsewhere, use `root` to point at the repository root.

## Choose a first run

- `terra-quality` processes changed and untracked source files and may apply safe fixes.
- `terra-quality quality --all --warn` checks every configured file without autofixes.
- `terra-quality --skip-commands` skips configured build/test commands for a fast static pass.

Continue with [configuration](/quality/configuration/) for all fields and [commands](/quality/commands/) for CI workflows.

## React and TSX projects

Set the JSX mode in the effective TypeScript project config so editors and project type checks compile `.tsx` files. For React projects, use `react-jsx`:

```json
{
	"compilerOptions": {
		"jsx": "react-jsx"
	}
}
```

When the config extends a framework preset, keep this option in the repository's own `tsconfig.json` if the editor reports that JSX is disabled. Restart the TypeScript language server after changing the config so stale diagnostics clear.

## Other packages

Install `@terra-symposium/error-boundaries` for React error boundary adapters; React and React DOM are peer dependencies. Install `@terra-symposium/reporting` for Playwright evidence, spreadsheets, and slideshows; `@playwright/test` is a peer dependency.
