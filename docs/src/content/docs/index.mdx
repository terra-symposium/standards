Standards maintains packages used across Terra Symposium applications. Each package has its own setup guide, public entry points, configuration reference, and known boundaries.

## Packages

| Package                                                          | Use it for                                                                     | Start here                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [@terra-symposium/standards-quality](/packages/quality/)                   | Configurable source checks, safe maintenance, and repository commands.         | [Install and set up](/packages/quality/setup/)                    |
| [@terra-symposium/standards-error-boundaries](/packages/error-boundaries/) | React render-error recovery and small framework-specific error helpers.        | [Use error boundaries](/packages/error-boundaries/)               |
| [@terra-symposium/standards-reporting](/packages/reporting/)               | Responsive Playwright runs, diagnostics, evidence artifacts, and load timings. | [Configure Playwright reporting](/packages/reporting/playwright/) |

All packages are published to the public npm registry. See [Contributing](/contributing/) to set up this workspace, change a package, or update these docs.

## Skills

Standards also publishes shared agent guidance for repository work, quality checks, issue audits, reporting, and interface review. Browse the [Terra skill library](/skills/) to find the workflows and source files.
