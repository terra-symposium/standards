---
title: Reporting
description: Create reusable Playwright evidence fixtures, spreadsheets, and slideshows.
---

`@terra-symposium/reporting` provides modules for Playwright evidence and reporting artifacts:

```ts
import { /* core exports */ } from '@terra-symposium/reporting';
import { /* Playwright helpers */ } from '@terra-symposium/reporting/playwright';
import { /* viewport helpers */ } from '@terra-symposium/reporting/viewports';
import { /* spreadsheet helpers */ } from '@terra-symposium/reporting/spreadsheet';
import { /* slideshow helpers */ } from '@terra-symposium/reporting/slideshow';
```

The core entry point defines visual result/run types and helpers such as `statusCounts()`, `orderedFiles()`, and `resultsForFile()`. The Playwright entry point provides the `diagnosticsTest` fixture plus diagnostic parsing helpers. The viewport entry point resolves the `PW_VIEWPORTS` selection, builds project names, and maps projects back to viewport sizes. The spreadsheet and slideshow entry points export `writeSpreadsheet()` and `writeSlideshow()`.

Use `withResponsivePlaywright()` around the repository's primary Playwright config to apply the shared six viewport sizes (390, 640, 768, 1024, 1280, and 1536 pixels), enable full-page screenshots, and attach the shared reporter. Every regular project is expanded automatically. Setup projects run once; list manual capture project names in `singleRunProjects` when needed. The default run uses all six sizes. Set `PW_VIEWPORTS=mobile,lg` for a focused run.

The reporter writes native screenshots to one timestamped `images` folder, one workbook row for each Playwright execution, and a PowerPoint slide for each logical test. Each test slide lays out its viewport previews together and labels missing captures. An optional `supplementalResultsFile` adds structured non-Playwright results to the workbook once; those rows do not create slides.

```ts
import { defineConfig } from '@playwright/test';
import { withResponsivePlaywright } from '@terra-symposium/reporting/viewports';

export default withResponsivePlaywright(defineConfig({
	projects: [{ name: 'app', testMatch: '**/*.spec.ts' }],
	// Keep the repository's server, authentication, and other Playwright options here.
}), {
	singleRunProjects: ['manual-auth-capture'],
	supplementalResultsFile: 'test-results/node-test-results.json',
});
```

`@playwright/test` version 1.52+ within the current major is a peer dependency. Spreadsheet and slideshow generation use included Excel and PowerPoint dependencies. Your repository owns scenarios, evidence naming, output paths, and CI artifact upload; consult the installed declarations for exact call signatures.
