title: Load testing
description: Capture page and operation timings and apply configurable budgets.

`@terra-symposium/standards-reporting` can attach timing measurements to Playwright results and grade each measurement against warning and failure budgets.

## Configure budgets

The default warning/failure thresholds are 2,000 ms and 5,000 ms. Configure global, per-test, and per-operation values in the repository's `quality.json`:

```json
{
	"loadTesting": {
		"enabled": true,
		"defaultBudget": { "warnMs": 2000, "failMs": 5000 },
		"testBudgets": {
			"tests/account.spec.ts::Account page loads": {
				"warnMs": 4000,
				"failMs": 8000
			}
		},
		"operationBudgets": {
			"load account summary": { "warnMs": 2500, "failMs": 5000 }
		}
	}
}
```

A test key uses `<repo-relative test file>::<full title path>`. Operation keys match the name passed to `measure`. Budgets are milliseconds, must be non-negative, and a complete budget's `failMs` must be greater than `warnMs`.

## Measure a test and named operations

Import `loadTest` for suites that need page-load and operation timings:

```ts
import { loadTest as test, expect } from '@terra-symposium/standards-reporting/playwright';

test('account summary loads', async ({ load, page }) => {
	load.setTestBudget({ warnMs: 4000, failMs: 8000 });

	await load.measure('load account summary', () => page.goto('/account'));

	await expect(page.getByRole('heading', { name: 'Account' })).toBeVisible();
});
```

The fixture records page navigation timing automatically. Use `load.measure(name, operation, budget?)` to time a synchronous or asynchronous operation; the helper returns the operation's value and records elapsed time even if it throws. `load.setTestBudget` applies an override to the test's total duration.

## Budget precedence and report behavior

For a named operation, a budget supplied directly to `measure` takes precedence over the matching configured operation budget, then the default. For test duration, the fixture override takes precedence over a configured test budget, then the default.

Measurements above `warnMs` are warnings; measurements above `failMs` are failures. The reporter includes grades and timing details in its artifacts, and a failed load budget marks the reporter run as failed.

The responsive helper passes settings from `quality.json` and explicit `loadTesting` options to the reporter. Explicit options override the matching file values. Set `loadTesting.enabled` to `false` to keep visual evidence while disabling new timing capture and enforcement.

For a non-Playwright test runner, provide a supplemental result file with `loadMeasurements` on each result. See [responsive Playwright](/packages/reporting/playwright/) for supplemental inventory setup and [artifact output](/packages/reporting/artifacts/) for report details.
