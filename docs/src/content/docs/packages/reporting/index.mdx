`@terra-symposium/standards-reporting` converts Playwright results into reusable diagnostic and review artifacts. It can expand regular projects across responsive viewports, capture browser diagnostics, write workbooks and slideshows, and grade load timings.

## Install

`@playwright/test` is a peer dependency for Playwright integrations:

```sh
pnpm add -D @terra-symposium/standards-reporting @playwright/test
```

The package supports Node.js `>=18.18` and `@playwright/test >=1.52.0 <2`. Spreadsheet, slideshow, and image-processing libraries are runtime dependencies of the package.

## Entry points

| Import path                                       | Use                                                                                                        |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `@terra-symposium/standards-reporting` or `/core` | Shared result types and helpers such as `VisualResult`, `ReportRun`, `statusCounts`, and `resultsForFile`. |
| `/playwright`                                     | The `diagnosticsTest`, `loadTest`, and `visualTest` fixtures, `ReportingOptions`, and `ProgressReporter`.  |
| `/viewports`                                      | Responsive configuration, the default viewport catalog, and project-name helpers.                          |
| `/load-testing`                                   | Load budget configuration, validation, and grading helpers.                                                |
| `/spreadsheet`                                    | `writeSpreadsheet()` for a normalized `ReportRun`.                                                         |
| `/slideshow`                                      | `writeSlideshow()` for review reports and `writeScreenshotSlideshow()` for image-only screenshot decks.    |

Start with [responsive Playwright integration](/packages/reporting/playwright/). See [load testing](/packages/reporting/load-testing/) for budget setup and [artifact writers](/packages/reporting/artifacts/) for workbook and slideshow output.

The package records test evidence. Your repository still owns test scenarios, authentication, server setup, application-specific evidence policy, and CI artifact retention.
