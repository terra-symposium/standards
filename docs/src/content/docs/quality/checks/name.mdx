---
title: Name
description: Find naming drift and apply safe syntax-aware identifier renames.
---

**Toggle:** `enabledChecks.name` · **Fix:** `autofix.name`

Finds naming drift and can apply safe whole-word or prefix-based renames. It considers syntax, scope, collisions, protected paths, exports, shorthand properties, and JSX. Ambiguous or conflicting edits remain findings.

Use `protectedIdentifiers` for stable domain names, public vocabulary, and abbreviations. Export renaming is disabled by default; `renameExports` opts in. `--strict` makes naming errors fail, while `--warn` reports without renaming. Review API-facing edits before accepting them.

**Before** — `command` is a configured long-word replacement:

```ts
const commandName = 'build';
run(commandName);
```

**After** — the safe rename updates the declaration and its references:

```ts
const cmdName = 'build';
run(cmdName);
```
