---
title: Command
description: Run explicit repository-owned quality commands such as build and test.
---

**Toggle:** `enabledChecks.command` and `enabledCommands.<name>` · **Fix:** none

Runs subprocesses declared in `qualityCommands` and propagates their status. The runner does not infer how to limit them to changed files. Each item has a unique `name`, executable `command`, and optional string-array `args`; commands run from `root`.

Use `enabledCommands` for per-command switches, `--skip-commands` for a one-run skip, or `enabledChecks.command: false` to disable the category. Document service and credential requirements in your workflow.
