**Toggle:** `enabledChecks.document` · **Fix:** `autofix.document` · **Command:** `document`

Maintains source headers, import grouping, section layout, whitespace, and TSDoc shape. It can scaffold minimal TSDoc tags to satisfy a configured documentation policy, but does not invent prose.

```json
{
  "documentation": {
    "required": { "types": true, "functions": true, "exportedFunctions": true, "noInlineFunctions": false }
  }
}
```

“Types” means classes, enums, interfaces, and type aliases. “Functions” means named function declarations. `exportedFunctions` can require only exported named functions when `functions` is false. `noInlineFunctions` reports arrow functions and function expressions and has no safe autofix. `maintain` remains a compatibility alias for `document`.

Generated placeholders are scaffolding. Replace them with descriptions of stable public intent and current signatures.
