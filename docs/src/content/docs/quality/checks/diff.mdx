title: Diff
description: Catch whitespace errors in the current Git worktree.
---

**Toggle:** `enabledChecks.diff` · **Fix:** none

Runs `git diff --check` to catch whitespace and patch errors. It requires Git and is worktree hygiene, not semantic review or generated-artifact validation. Disable it for source archives or environments without a Git worktree.

**Before** — `name: "Terra",␠` has a trailing space after the comma (`␠` marks the invisible space).

**After** — remove the trailing whitespace:

```js
name: "Terra",
```
