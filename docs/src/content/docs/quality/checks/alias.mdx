---
title: Alias
description: Find unnecessary compatibility aliases and repair supported references.
---

**Toggle:** `enabledChecks.alias` · **Fix:** `autofix.alias`

Reports compatibility aliases where the original identifier can be used directly. Supported fixes update references and imports while considering collisions and public contracts. Ambiguous cases remain findings.

Use it to retire temporary internal indirection. Review exported names and compatibility guarantees before enabling export-affecting cleanup.

**Before** — a private constant only forwards another local value:

```ts
const displayName = user.name;
return displayName;
```

**After** — use the value directly where the alias adds no useful meaning:

```ts
return user.name;
```
