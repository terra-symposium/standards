---
title: Lint
description: Invoke repository-configured ESLint on selected files.
---

**Toggle:** `enabledChecks.lint` · **Fix:** `autofix.lint`

Invokes ESLint and propagates its exit status. Fix mode passes ESLint's fix option. The package coordinates ESLint; it does not define or install your lint rules.

Set `tools.eslint` and optional `lintRoots`. Use native ESLint configuration for project-specific plugins and rules. Avoid broad automatic fixes for rules requiring product or security judgment.

**Before** — if the repository enables ESLint's `no-console` rule:

```ts
function saveRecord(record: RecordData) {
	console.log('saving');
	return persist(record);
}
```

**After** — remove or replace the disallowed logging according to repository policy:

```ts
function saveRecord(record: RecordData) {
	return persist(record);
}
```

The exact diagnostic and fix depend on the consuming repository's ESLint rules.
