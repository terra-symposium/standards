---
title: Format
description: Deterministic formatting through Prettier and canonical import layout.
---

**Toggle:** `enabledChecks.format` · **Fix:** `autofix.format` · **Command:** `format`

Runs Prettier over selected files and applies canonical layout protections, including configured long one-line import handling. Formatting changes presentation while preserving program meaning; it is separate from lint and semantic refactoring.

Configure `tools.prettier`, `prettierPrintWidth`, and `oneLineImports`. Prettier discovers its own native configuration. This package does not install Prettier.

**Before**

```ts
const result={name:'Terra',active:true};
```

**After** — Prettier applies the repository's configured layout:

```ts
const result = { name: 'Terra', active: true };
```
